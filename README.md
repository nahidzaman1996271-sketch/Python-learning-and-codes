## 📌 What Is This Repository?

This is my personal **Python learning journal turned codebase** — every chapter I've studied, every practice set I've grinded through, and every project born from "let me just try this real quick." It started as tangled, confusing code (relatable, right?) and slowly turned into structured chapters, clean practice sets, and full-blown projects.

If you scroll through the commits, you'll basically watch me learn Python in real time — theory one day, practice the next, and the occasional *"my pc is dying"* moment in between. 😅
